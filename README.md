# Veterans' Story Hour

Static GitHub Pages site for the Veterans' Story Hour campaign — Armed Forces veterans into schools, youth centres and libraries with lived stories of bravery, honour and civic pride.

**Repo:** https://github.com/rhodirish-afk/veterans-story-hour  
**Pages URL (once enabled):** https://rhodirish-afk.github.io/veterans-story-hour/

## Pages

- `index.html` — home
- `about.html` — purpose and tone
- `events.html` — inaugural pilot and forthcoming sessions
- `stories.html` — O'Leary VC and Gordon VC
- `involve.html` — speak, host, support, contact

## Enable GitHub Pages

1. Open **Settings → Pages** on this repository
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)`
4. Save — the site will appear at the Pages URL above (often within a minute or two)
