# Veterans' Story Hour

Static GitHub Pages site for the Veterans' Story Hour campaign — Armed Forces veterans into schools, youth centres and libraries with lived stories of bravery, honour and civic pride.

**Repo:** https://github.com/rhodirish-afk/veterans-story-hour  
**Pages URL:** https://rhodirish-afk.github.io/veterans-story-hour/

## Pages

- `index.html` — home (hero band)
- `about.html` — purpose and tone
- `events.html` — inaugural pilot and Oxfordshire outreach
- `stories.html` — O'Leary VC and Gordon VC (story cards)
- `involve.html` — speak, host, support, contact
- `css/styles.css` — navy / cream / crimson / gold campaign styles
- `assets/` — SVG mark, laurel, Open Graph image (`og.svg`)

## Design notes

- Fraunces + Source Serif 4; deep navy (`#0f1a24`), cream paper texture, crimson accent, subtle gold
- Dignified civic mark (abstract cross + laurel) — not militaristic kitsch
- Open Graph / Twitter card meta on every page; OG image at `assets/og.svg`
- Relative links suitable for Project Pages path `/veterans-story-hour/`
